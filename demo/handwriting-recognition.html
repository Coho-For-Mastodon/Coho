What to expect:

Gemini Nano uses an LLM to understand context and can handle messy handwriting, cursive, and even interpret unclear words from context. Tesseract.js is a traditional OCR engine optimized for printed text - it works best with clear, separated block letters.

How to Enable Chrome's Prompt API

  1. Open chrome://flags in Chrome Canary or Dev
  2. Search for Prompt API for Gemini Nano
  3. Enable the flag and restart Chrome
  4. The model may need to download (~1.7GB)
